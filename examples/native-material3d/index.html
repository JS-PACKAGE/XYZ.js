Native per-mesh shaders and spatial lights

The foreground sphere uses authored WGSL/GLSL vertex deformation and a borrowed pattern texture. Twenty-four local point lights and twenty-four spot lights illuminate separate tiles; bounded selection follows each mesh, not a single scene-wide light list. No audio is created.

Preparing native pipelines…

The failure button prepares an invalid descriptor without publishing it; the running scene remains intact. Canvas2D cannot run custom 3D shaders and reports that limitation explicitly. Deformation bounds are declared conservatively so native culling keeps the moving surface visible.
