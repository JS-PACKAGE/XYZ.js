Lightweight 2D · Firefly garden

Only Canvas-generated textures, Sprite, Text2D and a Scene update loop. Pause freezes the fireflies; reset returns them to their original flight phase.

Canvas2D needs no GPU renderer. GPU backend modules are loaded lazily when selected; this is the normal Game runtime, not a separate “microengine” or a promise of zero framework overhead. Unused physics, navigation and tween services stay uninitialized.
