# Rendering fixture font

`Abel-Regular.ttf` is an unmodified, 35,220-byte example/test data asset, not an engine dependency. The formal rendering example uses it to exercise actual `FontFace` loading, styled text, and generated RGBA glyph atlases. Its use does not change the root package license.
