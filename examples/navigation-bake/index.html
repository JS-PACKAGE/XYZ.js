Collision-baked navigation

Multiple overlapping XZ surfaces are baked with exact physics queries. Green nodes mark the ground and blue nodes mark the bridge. 120 capsule agents share one Scene scheduler; only supported stairs connect the bridge and underpass. Agents ignore each other but collide with the scenery.

Initializing…

Changing quota rebuilds the Scene with a new real scheduler budget and rebakes the same geometry. The quota bounds aggregate logical work, not milliseconds: CPU timing is an observer, not preemption. This is a finite multilayer sampled lattice with explicit bounds, not a polygon navmesh.
